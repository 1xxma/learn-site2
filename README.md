# LEARN — онлайн-репетиторы

Учебный веб-проект **ВВФ МТУСИ**: спокойные онлайн-уроки по школьным предметам, запись к репетитору и личный кабинет.

🌐 **Сайт:** [https://1xxma.github.io/learn-site2/](https://1xxma.github.io/learn-site2/)

---

## Возможности

- Каталог предметов и классов с поиском репетитора  
- Страницы репетиторов, расписание и запись на урок  
- Регистрация / вход, личный кабинет и «Мои записи»  
- Избранные репетиторы  
- Отзывы с фильтрами по предметам  
- Страницы «О нас», «Контакты», политика и согласие  
- PWA: можно добавить на экран телефона  

---

## Стек

- HTML, CSS, JavaScript  
- `localStorage` — аккаунты, записи и избранное  
- Service Worker + Web App Manifest — PWA  

Бэкенд-сервер не используется: данные хранятся в браузере пользователя.

---

## Структура

```text
learn-site2/
├── index.html          # Главная
├── subjects.html       # Предметы и поиск
├── reviews.html        # Отзывы

├── contacts.html       # Контакты и форма вопроса
├── login.html / register.html
├── profile.html        # Личный кабинет
├── schedule.html       # Запись на урок
├── tutor*.html         # Страницы репетиторов
├── privacy.html        # Политика и согласие
├── auth.js             # Авторизация, записи, избранное, PWA
├── style.css
├── sw.js / manifest.webmanifest / icons/
└── offline.html
```

## Локальный запуск

Для обычного просмотра можно открыть файлы напрямую.  
Для PWA нужен локальный сервер:

```bash
npx serve .
```

Затем откройте адрес из терминала (обычно `http://localhost:3000`).
