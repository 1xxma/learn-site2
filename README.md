# LEARN — онлайн-репетиторы

Учебный сайт проекта ВВФ МТУСИ: предметы, репетиторы, запись на уроки, личный кабинет, PWA.

## Открыть локально

Откройте `index.html` через локальный сервер (для PWA нужен HTTP/HTTPS, не `file://`).

```bash
npx serve .
```

## GitHub Pages

Settings → Pages → Deploy from branch `main` / root.
